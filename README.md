# 🥔 Potato Leaf Disease Detection using CNN & GenAI

An end-to-end AI-powered web application to detect potato leaf diseases from images and provide intelligent explanations and treatment recommendations using deep learning and Large Language Models (LLMs).

---

## 🚀 Project Overview

Potato crops are highly susceptible to diseases like **Early Blight** and **Late Blight**, which can significantly reduce yield if not detected early. This project uses a **Convolutional Neural Network (CNN)** to classify potato leaf images and integrates **Generative AI** to generate disease insights and remedies.

The system classifies leaves into:
- 🌿 Healthy  
- 🍂 Early Blight  
- 🍁 Late Blight  

and delivers AI-generated guidance through an interactive web app.

---

## 🧠 Key Features

- ✅ CNN-based image classification using **TensorFlow**
- ✅ Transfer Learning with **ResNet50** and **EfficientNetB0**
- ✅ Image preprocessing & augmentation
- ✅ **98% validation accuracy**
- ✅ Confusion matrix & classification report evaluation
- ✅ LLM-powered disease explanation & treatment suggestions
- ✅ Deployed as an interactive **Streamlit** web app
- ✅ End-to-end pipeline: Image → Prediction → AI Insights
